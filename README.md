# StateConsole project status and session handoff demo

StateConsole is a local-first desktop app for developers tracking multiple coding projects. In this documentation-only demo, a developer working on the fictional Lantern Notes project leaves a status update and picks up the work in a new coding session. You can follow the example in a text editor.

## Walk through the demo

1. Read [PROJECT_STATUS.md](PROJECT_STATUS.md) for the snapshot at the end of Session 1. Find the next actions, the unresolved tag decision, and the checks still pending.
2. Read [HANDOFF.md](HANDOFF.md) for the handoff and the decision made at the start of Session 2.
3. Use the [search checklist](docs/search-checklist.md) to compare a sample query with the fixture and see how to record an actual result.

Lantern Notes, the dates, and the application test results described in the snapshot and handoff are fictional. This repository contains no app implementation. The checklist includes a small text exercise and identifies which checks would require a running app.
